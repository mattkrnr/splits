Connect your data

Your account

The daily Garmin sync needs a sync token. It can only add your fitness data and can't read anything. Put it in the repo secret SPLITS_SYNC_TOKEN.

Garmin · daily auto-sync

A GitHub Action pulls your runs, other activities and sleep every morning around 5:30. To pull now or backfill a year: repo → Actions → Garmin sync → Run workflow.

Upload Garmin data by hand instead

Use this if the auto-sync can't reach Garmin. Run garmin_pull.py from the repo on any computer (or in a-Shell on iPhone): python3 garmin_pull.py --save-key once, then python3 garmin_pull.py --days 90, and upload the garmin.json it writes.

Fitbod · lifts

In Fitbod: Settings → Export Workout Data → Save to Files. Each upload replaces your earlier Fitbod data.

Clear imported data

Deletes your Garmin and Fitbod data from the database. The next daily sync brings back the last few days of Garmin data.
